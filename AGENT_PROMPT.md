# Промпт для агента: Decision Capsule

Сделай локальный дневник решений. Пользователь фиксирует вопрос, контекст, варианты, выбранный путь, уверенность и дату пересмотра, запечатывает запись, а позже открывает её и добавляет фактический итог.

MVP: создание капсулы, режим только для чтения до даты, список запечатанных/готовых/открытых капсул, экран открытия, поле результата, IndexedDB, импорт/экспорт JSON или Markdown, опциональная ссылка с данными в URL hash только после явного действия. Без регистрации, сети, email, AI и серверных напоминаний. Укажи, что дата берётся с устройства и hash не является шифрованием. Просроченная капсула открывается при следующем запуске.

Вайб: личный архив будущего — конверт, библиотечная карточка и календарь. Палитра: бордо #6F263D, пергамент #F2E8D5, латунь #B38A45, тёмный зелёный #31483B, уголь #242321. Шрифты: Libre Baskerville для вопросов и Inconsolata для дат/статусов. Используй линии сгиба, номер конверта и простую SVG-печать, без 3D. Много воздуха, один главный вопрос на экран. Никаких мотивационных цитат, градиентов, стеклянных карточек, pill-кнопок, мета-бейджей и давления «сделай сейчас». Основные действия: «Запечатать», «Открыть», «Добавить итог». Проверь копирование длинных ссылок, доступность клавиатурой и перенос через экспорт/импорт.


## Общие правила

- Сделай рабочий MVP как статический сайт для GitHub Pages.
- Не используй API-ключи, платные сервисы, обязательный backend, серверную базу данных, авторизацию или внешнюю AI-модель.
- Пользовательские файлы обрабатывай только в браузере; данные не отправляй на свой сервер.
- Если внешний URL упирается в CORS или лимиты, оставь полноценный локальный сценарий через ZIP, JSON или CSV.
- Сначала зафиксируй дизайн-систему и пользовательский сценарий, затем пиши код.
- Запрещены градиенты, glassmorphism, декоративные баблы, pill-кнопки, бесконечные карточки, bento-сетки, огромный hero-блок, CTA ради CTA и типичный AI/SaaS-дашборд.
- Не используй Inter, Roboto, Open Sans и похожие шаблонные пары как главный визуальный голос. Выбирай собственные шрифты с хорошей кириллицей и локальными fallback.
- Проверь desktop/mobile, клавиатуру, focus, reduced motion, пустые состояния и понятные ошибки.
