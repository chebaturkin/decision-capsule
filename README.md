# Decision Capsule

локальный архив решений. вы записываете вопрос, контекст, варианты, выбранный путь, уверенность и дату пересмотра. в назначенный день капсула открывается, и вы добавляете фактический итог.

данные остаются в `IndexedDB` этого браузера. аккаунта, сервера, аналитики и сетевых напоминаний нет.

## локальный запуск

```bash
npm install
npm run dev
```

откройте `http://127.0.0.1:5173`.

## перенос и ссылки

- **экспорт JSON** — полный архив с версией формата;
- **импорт** — сначала проверяет весь файл, показывает новые и повторяющиеся ID, затем добавляет только новые записи;
- **Markdown** — выгрузка одной капсулы для чтения или хранения рядом с заметками;
- **ссылка** — перенос одной капсулы через URL hash.

hash не является шифрованием. любой обладатель ссылки сможет прочитать вопрос, контекст и остальные поля капсулы, поэтому личными ссылками лучше не делиться.

дата пересмотра и статус считаются по локальной календарной дате устройства. если системные часы или часовой пояс изменены, результат будет соответствовать новым настройкам.

## проверка

```bash
npm test
npm run build
```

`npm run build` собирает статическую копию в `dist` для GitHub Pages. пользовательские данные при сборке не читаются и никуда не отправляются.
