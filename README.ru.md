# decision capsule

сохраните решение вместе с контекстом и вернитесь к нему в назначенный день, чтобы записать, что получилось.

[открыть приложение](https://chebaturkin.github.io/decision-capsule/?lang=ru)

капсула хранит вопрос, варианты, выбранный путь, уверенность и дату пересмотра. когда дата наступит, её можно открыть вручную и добавить итог. исходное решение остаётся неизменным.

## первая капсула

1. запишите вопрос и контекст, который хотите сохранить.
2. добавьте хотя бы два варианта, свой выбор и степень уверенности.
3. назначьте дату пересмотра, проверьте сводку и запечатайте капсулу.
4. вернитесь в этот день или позже, откройте капсулу и запишите, что получилось.

незаконченную капсулу можно оставить и позже продолжить с черновика. после запечатывания исходный вопрос, контекст и выбор остаются неизменными, чтобы их можно было сравнить с итогом.

## где хранятся данные

капсулы сохраняются в indexeddb, локальном хранилище этого браузера. аккаунта, серверной базы и аналитики нет. при очистке данных браузера архив может исчезнуть. перед очисткой или переходом в другой браузер скачайте резервную копию в json.

дата пересмотра считается по календарю и часовому поясу устройства. приложение не отправляет напоминания: открыть капсулу нужно самостоятельно.

## перенос записей

- **скачать архив**: сохранить все капсулы в json-файл;
- **загрузить архив**: проверить файл, показать новые и повторяющиеся капсулы, затем добавить новые после подтверждения;
- **скачать заметку**: сохранить одну капсулу в markdown с подписями на текущем языке интерфейса;
- **ссылка на капсулу**: перенести одну запись через ссылку.

данные в ссылке не зашифрованы. любой, у кого она есть, сможет прочитать капсулу. запечатывание сохраняет исходную запись внутри приложения: это не пароль и не способ скрыть файл от человека, который пользуется вашим устройством.

## локальный запуск

```bash
npm ci
npm run dev
```

откройте локальное приложение на [русском](http://127.0.0.1:5173/?lang=ru) или [английском](http://127.0.0.1:5173/?lang=en).

приложение написано на html, css и javascript, без фреймворка. шрифты и логотип не требуют внешних запросов.

## проверка и сборка

```bash
npm test
npm run build
```

сборка создаёт статические файлы в `dist` для github pages. пользовательские данные при этом не читаются.

при запущенном локальном сервере можно пройти сценарии в браузере. для этой проверки нужны python и playwright с установленным chromium:

```bash
python3 tests/ui_smoke.py
I18N_URL=http://127.0.0.1:5173 python3 tests/i18n_browser.py
```

проверки создают записи в отдельном временном браузере: создание, сохранение черновика, открытие, итог, поиск, фильтры, сортировка, импорт и экспорт. также проверяют фокус в диалогах, переключение языка и ширину страниц на телефоне. ваши данные они не используют.

чтобы обновить русские демонстрационные скриншоты:

```bash
python3 tests/ui_smoke.py --screenshots
```

## язык

ru / en в шапке меняет язык без перезагрузки. явный `?lang=ru` или `?lang=en` важнее сохранённого выбора, затем учитывается первый поддерживаемый язык браузера. по умолчанию используется английский. черновик, несохранённый итог, архив и параметры ссылки остаются на месте. ваши записи не переводятся.
