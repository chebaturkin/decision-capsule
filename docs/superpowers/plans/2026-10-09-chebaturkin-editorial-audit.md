# Decision Capsule editorial and interface audit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** привести интерфейс Decision Capsule, пользовательские сообщения, метаданные и README к одному ясному русскому голосу с согласованной терминологией и проверить найденные места риска без изменения пользовательского сценария архива.

**Architecture:** сохранить статическую архитектуру и IndexedDB-модель. Тексты остаются рядом с представлениями в `app.js`, экспортируемые документы — в `lib/model.js`, описание проекта — в `README.md`, а визуальная настройка — в `styles.css`. Технические имена, формат данных и hash-ссылка остаются совместимыми; меняются только человекочитаемые строки, доступные названия и небольшие защитные проверки.

**Tech Stack:** vanilla JavaScript modules, IndexedDB, static HTML/CSS, Node.js test runner, GitHub Pages.
